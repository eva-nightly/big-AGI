# Module: public/workers

Provides a pre-built, minified Mozilla PDF.js web worker (v5.4.54) static asset to parse, render, and process PDF documents off the main browser UI thread.

_`public/workers/pdf.worker.min.mjs` is larger than one call on its own (~259282 tokens): only its first ~39992 were read._

## Key files
- `public/workers/pdf.worker.min.mjs`: Standalone bundled web worker script for PDF parsing, text extraction, and rendering
