# Module: public

Provides static web assets for the application, including a standalone fallback notification page shown when a tab or session has been transferred to another window.

## Key files
- `public/closed.html`: Static HTML page informing the user that the session has moved to another window, advising them to close the tab or reload back to the root application.

## Public interface
- /closed.html
