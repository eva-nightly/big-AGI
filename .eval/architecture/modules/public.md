# Module: public

Serves a static HTML notice page informing the user that their session was moved to another window or tab, prompting them to close the tab or reload the application.

## Key files
- `public/closed.html`: Static fallback HTML page indicating the session moved to another window with a reload link.

## Public interface
- /closed.html static HTML route
