# Module: public

Provides static assets and fallback HTML pages, such as the closed session notification page shown when a session moves to another browser window.

## Key files
- `public/closed.html`: Static HTML page informing the user that the session has moved to another window, advising to close the tab or reload the application.

## Public interface
- /closed.html
