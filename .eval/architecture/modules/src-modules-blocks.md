# Module: src/modules/blocks [AI]

(part 1 of 2) Renders, highlights, and manages code and rich content blocks generated by language models (including syntax highlighting, Chart.js charts, Mermaid diagrams, PlantUML diagrams, SVG graphics, sandboxed HTML iframes, and markdown), providing interactive features such as code diffing, collapsing, file saving, AI-powered error fixup, and LiveFile workspace patching. (part 2 of 2) Parses and renders various chat and message content blocks including rich markdown, LaTeX formulas, code snippets, dangerous HTML, images, and text diffs with support for streaming/decay optimization and task toggling.

_This module does not fit in one model call, so it was read in 2 parts and their summaries were combined without a further model call._

## Key files
- `src/modules/blocks/code/RenderCode.tsx`: Core code block rendering dispatcher that coordinates dynamic Prism syntax highlighting, renderer selection, overlay toolbars, copy/download actions, and fullscreen modes.
- `src/modules/blocks/enhanced-code/EnhancedRenderCode.tsx`: Enhanced code panel providing collapsible framing, metadata tooltips, context menus, LiveFile patch action bars, and diff comparison hooks.
- `src/modules/blocks/code/code-highlight/codePrism.ts`: Utility module providing Prism-based syntax tokenization, language inference from titles/extensions/incipits, and line numbering.
- `src/modules/blocks/code/code-renderers/RenderCodeChartJS.tsx`: Interactive Chart.js chart renderer with dynamic library loading, theme support, PNG export, and AI code fixup integration on parse/render errors.
- `src/modules/blocks/code/code-renderers/RenderCodeMermaid.tsx`: Mermaid diagram renderer with CDN script loading, SVG cleanup, PNG export, and AI code fixup triggers on diagram syntax errors.
- `src/modules/blocks/code/code-renderers/RenderCodePlantUML.tsx`: PlantUML diagram renderer that compresses code, fetches SVGs from a PlantUML server, supports theme and direction cycling, and triggers AI fixups on errors.
- `src/modules/blocks/code/code-renderers/RenderCodeHtmlIFrame.tsx`: Sandboxed iframe renderer executing interactive HTML/JS code with isolated storage shims and keyboard event guards.
- `src/modules/blocks/danger-html/RenderDangerousHtml.tsx`: Security warning wrapper for raw HTML blocks that provides user confirmation before rendering in sandboxed iframes.
- `src/modules/blocks/enhanced-code/ERCDiffContext.tsx`: Context provider and hooks managing base and comparison code states for side-by-side or unified code diff viewing.
- `src/modules/blocks/enhanced-code/livefile-patch/useLiveFilePatch.tsx`: Hook integrating code block outputs with local workspace LiveFiles to generate and apply file overwrites.
- `src/modules/blocks/AutoBlocksRenderer.tsx`: Central block dispatcher that decomposes message text into typed blocks and renders appropriate specialized block components.
- `src/modules/blocks/markdown/RenderMarkdown.tsx`: Markdown renderer entry point supporting full lazy markdown rendering and lightweight non-parsed streaming fallback (RenderMarkdownLite).
- `src/modules/blocks/markdown/CustomMarkdownRenderer.tsx`: Configures ReactMarkdown with remark/rehype plugins (KaTeX, GFM, task lists, table breaks, mark highlighting) and timing instrumentation.
- `src/modules/blocks/markdown/HostedLinksContext.tsx`: Context provider enabling markdown links to execute actions provided by message-scoped sibling blocks (such as model sandbox files).
- `src/modules/blocks/image/RenderImageRefDBlob.tsx`: Renders database-stored image assets with metadata overlays and support for prompt-based AI regeneration.
- `src/modules/blocks/image/RenderImageURL.tsx`: Renders direct image URLs and markdown image references with card/attachment variants, zoom, and action overlays.
- `src/modules/blocks/plaintext/RenderPlainText.tsx`: Renders plain text and highlights chat slash commands.
- `src/modules/blocks/wordsdiff/RenderWordsDiff.tsx`: Renders insertions and deletions computed via word-level diffing.
- `src/modules/blocks/blocks.hooks.ts`: Provides hooks for block stabilization across streaming updates and height-based collapsing.
