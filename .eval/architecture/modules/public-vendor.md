# Module: public/vendor

Provides static third-party vendor assets, specifically the standalone minified SheetJS (xlsx) library for client-side spreadsheet data parsing and handling.

_`public/vendor/sheetjs/xlsx-0.20.3.mini.min.js` is larger than one call on its own (~69768 tokens): only its first ~39992 were read._
