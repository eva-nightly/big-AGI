# Module: public/vendor

Provides a vendored, minified distribution of the SheetJS (xlsx) library (version 0.20.3 mini) for client-side spreadsheet parsing and file processing.

_`public/vendor/sheetjs/xlsx-0.20.3.mini.min.js` is larger than one call on its own (~69768 tokens): only its first ~39992 were read._

## Key files
- `public/vendor/sheetjs/xlsx-0.20.3.mini.min.js`: Vendored SheetJS library bundle providing the global XLSX object for parsing and formatting tabular/Excel data.
