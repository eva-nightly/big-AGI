# Module: public/vendor

Provides a standalone, minified vendor distribution of the SheetJS (xlsx) library for client-side parsing and processing of spreadsheet files.

_`public/vendor/sheetjs/xlsx-0.20.3.mini.min.js` is larger than one call on its own (~69768 tokens): only its first ~39992 were read._

## Key files
- `public/vendor/sheetjs/xlsx-0.20.3.mini.min.js`: Minified build of SheetJS (version 0.20.3) establishing the global XLSX spreadsheet processing object.
