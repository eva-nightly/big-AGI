# Goals

_What "good" means to this company, in the order the sources gave them._

1. Every answer is helpful, accurate, on-topic, follows the prompt and the chosen persona, with a clear message when a model fails.
   > "Right means a helpful, accurate, on-topic answer that follows the prompt and the chosen persona, and a clear message when a model fails."
   >
   > — `About_the_organisation.md`


2. Users get a useful answer on the first try and keep chatting.
   > "Success looks like: users get a useful answer on the first try and keep chatting."
   >
   > — `big-agi-business.md`


3. Fast streaming answers and clear errors when a model is unavailable.
   > "Key promise: fast streaming answers, clear errors when a model is unavailable."
   >
   > — `big-agi-business.md`


4. This quarter: reliable chat, clearer error messages, and easier model selection.
   > "Priorities this quarter: reliable chat, clearer error messages, easier model selection."
   >
   > — `big-agi-business.md`


5. Avoid the known risks: model outages, wrong or off-topic answers, slow streaming, and confusing model choice.
   > "Risks: model outages, wrong or off-topic answers, slow streaming, confusing model choice."
   >
   > — `big-agi-business.md`
